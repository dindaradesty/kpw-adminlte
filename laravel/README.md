# PerpusKita - Tugas KPW

Project Laravel perpustakaan menggunakan AdminLTE dan Query Builder.

## CRUD
Setiap menu utama memiliki Read, Lihat Detail, Edit, dan Hapus. Form Tambah tetap tersedia pada halaman masing-masing.

Menu: Buku, Kategori, Anggota, Peminjaman, Pengembalian.

## Menjalankan project
1. Copy `.env.example` menjadi `.env` dan atur database MySQL/MariaDB.
2. Jalankan `composer install`.
3. Jalankan `php artisan key:generate`.
4. Jalankan `php artisan migrate`.
5. Jalankan `php artisan serve`.

Login demo: `admin` / `12345`.
